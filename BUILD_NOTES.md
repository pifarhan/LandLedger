# Build notes — LandLedger v15 (14-Nov-2026)

See `LANDLEDGER_FINAL_BUILD_REPORT.md` for scope, exact evidence and limitations.

This package is built from the full V13 project tree, not the earlier small V14 rebuild. It includes the original Survey of India ABDB RAR, the derived all-India ABDB administrative hierarchy, the 36-State/UT DILRMP aggregate snapshot, NGDRS live/manual feeds, blank default ledger, updated claimant workflow, data provenance, automated tests and verification scripts.

No fabricated owners or sample property records are included. It is an academic prototype, not a government registry or production deployment.
